# Feature implementation map

| Area | Implemented components |
|---|---|
| Recipes | CRUD, metadata, nutrition, ingredients, steps, tools, categories, tags, favorites, cook counter |
| Search | Structured filters, full-text query, dashboard statistics, Nextcloud unified search provider |
| History | Revision snapshots, revision list and restore |
| Duplicate management | Similarity scoring and guided merge endpoint/UI flow |
| Import | URL, text, HTML, Markdown, JSON and uploaded files |
| Web extraction | Schema.org Recipe / JSON-LD, Open Graph/readable-text fallback |
| Text parsing | Multilingual sections, fractions, quantities, units, servings, times, tools and instructions |
| OCR/documents | Local Tesseract/Poppler adapter and configurable external multipart adapter |
| AI | Nextcloud Task Processing, OpenAI-compatible, Anthropic and Gemini providers |
| Media | Nextcloud Files storage, cover images, safe downloads and attachment metadata |
| Planner | Dated meal slots, servings and notes |
| Shopping | Multi-recipe aggregation, serving scaling, manual items and checked state |
| Sharing | User, group and password/expiry-protected public links |
| Export | JSON-LD, Markdown and printable HTML |
| Notifications/jobs | Queued import job, import completion/failure notifications and retention cleanup |
| Internationalization | English and Italian Nextcloud translation catalogues |
| UI | Dashboard, library, editor, import preview, planner, shopping lists, settings and public page |
| Extensibility | Importer, AI provider, OCR provider and exporter interfaces/registries |
